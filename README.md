# فلوسي — Floosy PWA

تطبيق ويب تقدمي عربي RTL لإدارة دخل ومصروفات وحسابات وفواتير وديون وأهداف ادخار. يدعم العمل دون اتصال بعد تحميله أول مرة، ويخزن السجلات محليًا في IndexedDB. النسخ الاحتياطي والاستعادة من داخل التطبيق بصيغة JSON.

## النشر على GitHub Pages

1. أنشئ مستودع GitHub جديدًا. اجعله **Private** إذا أردت إبقاء مصدر التطبيق غير عام (إتاحة GitHub Pages للمستودعات الخاصة تعتمد على نوع حسابك/الخطة).
2. ارفع كل ملفات هذا المشروع ومجلد `.github/workflows` إلى الفرع `main`. لا ترفع نسخ JSON الاحتياطية أو بيانات شخصية.
3. من المستودع افتح **Settings → Pages**، واختر **GitHub Actions** كمصدر النشر.
4. افتح تبويب **Actions** وانتظر نجاح مهمة **Deploy Floosy to GitHub Pages**.
5. سيظهر عنوان الموقع في **Settings → Pages**. يكون عادةً `https://USERNAME.github.io/REPOSITORY/` للمستودع العادي، أو `https://USERNAME.github.io/` لمستودع الموقع الشخصي.
6. افتح العنوان المنشور. كل تحديث تدفعه إلى `main` سيشغّل النشر مجددًا.

ملف سير العمل `.github/workflows/pages.yml` ينشر الملفات الثابتة تلقائيًا. استخدم رابط Pages الناتج فعلًا؛ لا تفترض الرابط قبل نجاح النشر.

## تثبيت على iPhone

افتح رابط HTTPS المنشور في Safari، اضغط زر المشاركة، اختر **إضافة إلى الشاشة الرئيسية**، ثم افتح فلوسي من الأيقونة. سجّل بياناتك بعد التأكد من أن هذا هو جهازك الشخصي.

## البيانات والخصوصية

هذه النسخة تحفظ البيانات محليًا في متصفح الجهاز فقط. لا يوجد تسجيل دخول أو قاعدة بيانات سحابية أو مزامنة بين الأجهزة. استضف الموقع على HTTPS، لكن HTTPS لا يحول IndexedDB إلى تخزين سحابي. استخدم «تنزيل نسخة احتياطية» دوريًا واحفظ ملف JSON في مكان خاص وآمن. لا تضع النسخة الاحتياطية أو أي بيانات مالية في مستودع GitHub، خصوصًا إذا كان عامًا. استعادة JSON تضيف سجلاتها إلى بيانات المتصفح الحالي. مسح بيانات Safari أو حذف بيانات الموقع قد يحذف السجلات؛ التخزين المؤقت للأصول ليس نسخة احتياطية.

## ملاحظات

لا تتضمن هذه النسخة توليدًا آليًا لمواعيد الفواتير المتكررة أو تزامنًا أو إشعارات خلفية. GitHub Pages يستضيف ملفات ثابتة فقط ولا يوفر قاعدة بيانات أو مصادقة للتطبيق.
